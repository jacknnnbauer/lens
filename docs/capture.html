划词取词

不离开正在读的东西，
就把词查了、把句子存了

在浏览器、PDF、Word、邮件、聊天软件里选中一个词，按一下快捷键。查词小窗贴着你的阅读位置弹出；这个词所在的那句话、来自哪个程序和网页，一起记下来。

Whenever I find myself growing grim about the mouth; whenever it is a damp, drizzly November in my soul; … then, I account it high time to get to sea as soon as I can.

示意：在浏览器里选中 drizzly，按快捷键，旁边弹出的就是 Lens 的查词小窗（真实截图）。

两种触发方式

全局快捷键默认 Ctrl+Alt+Space，在设置里点一下再按新组合就能换；被别的程序占用时会提示。
连按两次 Ctrl+C选中文字后快速连按两次 Ctrl+C。不用记新快捷键，复制的手势顺手就查了；不需要时可以关掉。

自动抓原句，记下出处

Lens 用 Windows 的 UI Automation 读取你选中的位置和它周围的段落，切出包含这个词的那一句。以后在生词本里看到的，不是一个孤零零的单词，而是你当时读到的那句话。

  • 切句准：合并 PDF 复制常见的断行和连字符，不会在 Mr.、e.g.、U.S. 这类缩写后面误切。
  • 记来源：程序名、窗口标题；浏览器还会读出当前网址，以后点来源能回到原网页。
  • 句子太短？小窗里「+ 前句 / 后句 +」（Alt+← / →）多带一句，扩展后的句子写回保存的语境。
  • 读不到也能查：有的程序不支持 UI Automation，就退回用剪贴板里的文字查词；超过等待时间先弹窗，不让你干等。

查词小窗

  • 无边框、置顶、不占任务栏；后台预先建好，弹出几乎没有延迟。
  • 上面是「当前语境」：这个词在这句话里是哪个意思；下面是各部词典的卡片和高亮了单词的原句。
  • 钉住（Ctrl+P）：失焦不自动关闭，再查词也留在原处，可以先挪到不挡视线的地方。
  • 拖边缘调大小、拖顶部移动，松手记住。
  • Enter 展开到主窗口、Ctrl+S 收藏、Tab 切词典、Esc 关闭。

在 Lens 里面也能随手查

释义、例句、生词本的语境句里遇到不认识的词，直接查。三种方式任选：双击（默认）、单击（像 Kindle）、拖选后松开。查的时候同样记下所在句子，收藏时一起保存。

查过的词，自动进生词本

  • 划词时加入生词本：查到释义后自动收进生词本，连同原句；已经收过的词只追加新句子。
  • 主窗口查词时加入：只算确定的查询（回车、点候选、点链接），打字过程中的联想不算。
  • 查不到的也能收：词典里没有的词组（如 first year）也能连同原句收藏，释义自己写。
  • 按原形合并：选中的是 convulsed，生词本里记的是 convulse，一个词可以有很多条语境。
